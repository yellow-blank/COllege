## ▶️ How to Run a Practical

1. Open the `OOP-Using-Python-Practicals` folder in VS Code.
2. Select **Terminal → New Terminal** from the top menu.
3. Run the Python file you want to test. For example:

   ```bash
   python 01_quadratic_roots.py
   ```

4. Follow the prompts and enter the requested values in the terminal.

**If `python` does not work:**
- On Windows, try `py`.
- On macOS or Linux, try `python3`.

Replace the example filename with the practical you want to run. Each program can be executed independently.

## 📝 Special Note: Practical 09 — File Handling

These output files are generated when the program runs.
